# QA Testing Portfolio

## Project: SauceDemo Login Testing

This project demonstrates manual QA testing of the SauceDemo login functionality.

### Scope
- Login validation
- Error handling
- Edge cases

### Test Coverage
- Valid login
- Invalid credentials
- Locked user
- Empty fields

### Deliverables
- Test Plan
- Test Cases
- Bug Reports
- Evidence (Screenshots)

### Tools Used
- Git & GitHub
- Manual Testing

### Workflow
- Created feature branch
- Added test documentation
- Submitted Pull Request
- Merged into main branch
