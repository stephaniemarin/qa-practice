# QA Testing Portfolio

## Project: SauceDemo Login Testing

This project demonstrates manual QA testing of the SauceDemo login functionality.

### Scope
- Login validation
- Error handling
- Edge cases

### Test Coverage
- Valid login
- Invalid credentials
- Locked user
- Empty fields

### Deliverables
- Test Plan
- Test Cases
- Bug Reports
- Evidence (Screenshots)

### Tools Used
- Git & GitHub
- Manual Testing

## Test Scenarios Covered

- Valid login
- Invalid password
- Locked user
- Empty fields (edge case)
- Error message validation

## Example Bug

**Bug:** Login allows empty password  
**Expected:** Error message displayed  
**Actual:** Login attempt proceeds without validation
